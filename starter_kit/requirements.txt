# LoomQ 依赖锁定文件
#
# 题面要求：第三方依赖必须精确锁定版本（写 >= 会被拒）。正式评测在
# python:3.10-slim 容器内执行 pip install --no-cache-dir -r requirements.txt。
#
# 版本不是随手取的，三个约束缠在一起，改动任何一行都可能连锁崩掉：
#
#  1. Python 必须是 3.10。spinqit 只有 cp38/cp39/cp310 的 wheel 且无 sdist，
#     上限 3.10；而最新的 amazon-braket-sdk 要求 >=3.11。3.10 是唯一交集。
#
#  2. antlr4-python3-runtime 必须是 4.9.2。spinqit 硬钉 4.9.2，而
#     amazon-braket-default-simulator >=1.28.0 硬钉 4.13.2，两者不可调和
#     （ANTLR 4.10 改了序列化 ATN 格式，4.9 生成的解析器在 4.13 运行时会崩）。
#     所以 default-simulator 必须停在 1.27.0 —— 它是最后一个用 4.9.2 的版本。
#
#  3. amazon-braket-sdk 必须是 1.97.0。它与 default-simulator 1.27.0 同日发布，
#     是能与之配套的最后一版。更高的 SDK（如 1.100.0）虽然声明
#     default-simulator>=1.27.0，实际却会 import VerbatimBoxDelimiter ——
#     那个符号 1.27.0 里没有，直接 ImportError。声明的下界不等于真实兼容性。
#
# 已实测：本文件在 Python 3.10.11 上装出的环境，evaluator L1 四个 case 全 PASS，
# 六个隐藏回归电路 × spinq/braket 两后端保真度均 >=0.989。
#
# 关于 Linux 可装性（已逐包核对 PyPI）：全部 65 个包在 linux/cp310 上都有
# 现成 wheel，只有 antlr4-python3-runtime 与 python-constraint 需从 sdist 构建，
# 二者都是纯 Python，不需要编译器，slim 镜像足够。
#
# pyqpanda（本源 originq）未列入：属 L1 进阶项，尚未验证，装不上不影响资格线。
