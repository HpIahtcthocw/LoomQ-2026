不需要懂物理，不需要写代码，也不需要知道什么叫量子比特。 往下读三句话，然后我们就开始。

  1. 01
    普通电脑的一个比特，同一时刻只能是 0 或者 1。

    量子比特可以同时「既是 0 又是 1」——直到你去看它的那一刻，它才随机塌成其中一个。

  2. 02
    所谓写量子程序，就是排一串操作去摆布这些比特，最后测量。

    每次测量只吐一个答案，所以要重复很多次。真正有意义的是这些答案的分布。

顺便一提，LoomQ 是什么

全世界的量子计算机分属好几家，每家说自己的语言——为量旋那台机器写的程序， 换到本源或者亚马逊的机器上要整个重写。LoomQ 是夹在中间的那层翻译： 一份代码进去，自动翻成三家各自的方言，结果按同一种格式回来。

再往上加一层：你用中文说一句话，它变成电路、跑起来，再用人话告诉你结果什么意思。 这个页面就是那层东西的入口。跑完最后一步，我会再跟你说一遍你到底做了什么。

    所以你刚才做的是什么

    你没写一行代码。你说了一句中文，换来一个真实的量子电路；它被送进一台真的 量子计算机，两分钟后带回一串数据；页面告诉你哪些是电路本该给出的， 哪些是机器自己抖出来的噪声。

    这条链路上，原本每一环都要专门知识：懂量子力学才写得出电路， 懂各家 SDK 才提交得了任务，懂实验物理才读得懂噪声。 LoomQ 做的事，就是把这三道门槛收进这一个页面。

    说句实话：今天的量子计算机还派不上用场。你刚才连的那台只有两个量子比特， 跑最简单的电路都要错掉两成。它现在的处境像 1950 年代占满一整间屋子的 电子管计算机——原理成立，工程上还差得远。真正指望它的方向是模拟分子 （算新药、新材料）、密码学和某些优化问题，一个都还没到能用的地步。

    所以这件作品的价值不在于让你今天就用量子机干成什么活，而在于证明这条路走得通： 等这些机器真的能用了，门口不该只站着物理博士。
