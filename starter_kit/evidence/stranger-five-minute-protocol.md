# 陌生用户测试怎么做

找一位没看过这个项目、也没参与开发的人来用一次。下面是测试步骤，做完后把实际情况写进 `stranger-five-minute-test.md`。

## 开始前

主持人提前把服务、模型和真机凭据配好，配置不计时。测试开始后不要解释页面，也不要替用户点按钮。

```text
Windows: 双击 start.ps1
macOS/Linux: ./start.sh
```

把键盘交给被试，只说：“你随便点，我不出声。”被试点“开始计时”后开始计时。五分钟到点就停，不补做没完成的步骤。

## 最后问一句

完成页面选择题后，只问一次：“你刚才让那台机器做了什么？为什么会得到这些结果？”把回答原样记下来。选择题答对不等于用户真的能解释，所以这句要保留。

```text
被试原话：

```

## 判定

只有实际完成并如实填写后，才能把本项标为通过。若真机离线、超过五分钟或被试无法解释原理，应照实记录，不用模拟器结果替代真机证据。
