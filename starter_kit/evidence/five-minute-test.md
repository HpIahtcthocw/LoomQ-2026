# 五分钟引导实测记录

专项奖「最佳包容性设计与优秀体验奖」的评选标准原话：

> 让一位没有任何量子背景的跨界创作者，在 5 分钟内依靠智能体引导，
> 成功在真实量子机上完成人生第一个实验，并理解其科学原理。

这份文件是对着这句话逐条取证。**未填完之前，这一项按未完成计。**

## 怎么做这次实测

**主持人只做两件事：计时、记录。** 全程不要提示、不要解释、不要代劳。
被试卡住的地方就是产品的缺陷，替他跨过去等于把证据毁掉。

1. 主持人先把服务起好（这一步不计时）：双击 `start.ps1`，或在终端里跑
   `./start.sh`。浏览器会自动打开。
2. 把键盘交给被试，说一句「你随便点，我不出声」，然后开始计时。
3. 被试自己读开场、点「读完了，开始计时」——页面上的计时器就是这次的秒表。
4. 记录下面每一栏。原话要照抄，不要转述成书面语。

## 一、被试

**这一栏必须照实填，包括对结论不利的部分。** 如果被试是项目作者本人，就写作者
本人——他没有量子背景这件事是真的，能证明「不懂量子的人读不读得懂这些解释」；
但「第一次见这个产品」不成立，证明不了「陌生人能否自己走通」。两种证据的效力
不同，混为一谈评委一眼能看出来。理想情况是再找一位真正没见过的人补一份。

| 项目 | 填写 |
|---|---|
| 化名或代号 | A（项目作者本人） |
| 与本项目的关系（作者本人 / 完全陌生 / 见过但没用过） | **作者本人**。这一点决定了本次证据的效力边界，见下 |
| 职业 / 专业背景 | 学生，非物理、非量子相关专业 |
| 是否学过物理（哪个阶段） | 大学普通物理（非物理专业），没学过量子力学 |
| 是否写过代码 | 会一点，不是主业 |
| 此前是否听说过量子计算 | 听说过，无系统学习 |
| 此前是否用过量子计算平台 | 本项目之外没有用过 |
| 实测日期 | 2026-08-12（第一轮，约 20:20 UTC+8） |
| 主持人 | 无第三方主持，作者自测自记 |

**这份证据能证明什么、不能证明什么，先说清楚。**

能证明：一个没有量子背景的人，看着这些解释文字，**看不看得懂**。作者虽然写了
这个产品，但他确实没有量子物理背景，读不懂"贝尔态""受控非门"这类词是真实
反应——第一轮实测的结论正是"基本都没看懂"，这个否定结论不可能是自己给自己
放水放出来的。

不能证明：一个**从没见过这个页面的陌生人**能否独立走通。作者知道每个按钮在
哪、下一步该点什么，"五分钟内完成第一个实验"这条在他身上偏乐观。这条判据
要真正站住，需要再找一位真正的陌生人补一轮。**在补上之前，本项目不宣称这条
已经证实。**

## 八、这次实测暴露的问题

按严重程度排，写清楚要改什么。这一栏为空是不正常的。

1. **术语先于人话出现，导致整页读不懂。** 标题写"两比特贝尔态"，解释跟在
   后面；对没学过的人这个标题不承载任何信息。这是第一轮唯一但致命的问题，
   直接导致"理解其科学原理"不成立。
2. **真机整片离线时给的原因是错的。** 提示写"没有任何平台能装下 2 比特的
   电路"，而 `gemini_vp` 本身就是 2 比特——真实原因是 0 台在线。把"机器没开"
   说成"你的电路太大"，等于甩锅给用户。
3. **连不上真机时不分原因，一律回同一句话。** 没配账号时也说"真机常常一台
   都不在线"，而那时机器可能好好开着。理由说得体贴但与事实不符。
4. **结果页的操作步数与图上方块数对不上。** 文字说"2 个门"，图上有 4 个
   方块（测量没算进去）。用户数一遍发现对不上，只会怀疑自己看错。
5. 平台代号 `gemini_vp`、位串写法 `c[1] c[0]` 直接出现在面向用户的文案里。
6. **真机那一步等不到结果。** 被试原话："正在送往真实的量子计算机这个地方
   还是不行"，自述只等了 30 到 60 秒。而真机一次来回实测要 100 到 110 秒——
   他从来没等到过。等待期间页面只有一个走秒的计数，秒表能证明页面还活着，
   证明不了等下去有意义。他一度提出"是不是应该把这部分删掉"。

## 九、据此做了什么

第一轮实测后按上面五条逐条改，改动集中在 commit `aa088ce`：

| 问题 | 改法 |
|---|---|
| 1 | 人话上位、学名退成注脚：标题改为"让两个比特永远给出一样的答案"，下方小字"学名：两比特贝尔态"。术语保留，供查证 |
| 1 | 「受控非门」「纠缠」「均匀叠加」「干涉」「线路深度」在第一次出现处就地跟一句解释 |
| 1 | 开场第一屏当场定义「电路」「门」「测量」，并与结果页三个区块标题对齐 |
| 2 | 区分"一台机器都没开着"与"机器开着但装不下"，分两句话讲 |
| 3 | 连不上真机按三种原因（没配账号／电路太大／机器离线）分别给理由 |
| 4 | 改为"2 步操作加最后 2 个读数方块（写着 M 的那种）" |
| 5 | 平台代号补中文名（双子座 Gemini，代号 `gemini_vp`）；位串读法改用人话 |
| 6 | 排队期间先把同一个电路的模拟结果整屏摆出来（实测 1.1 秒上屏），真机回来后整屏替换并给出偏差解释。等待从"空耗"变成"等真机回来做对照"，"跑出第一个实验"不再被排队时间绑架。见 `files/webui/10-pending.png` |

第 6 条没有采纳"删掉真机这部分"的提议。判据原话是"成功在真实量子机上完成
人生第一个实验"，真机是这个专项奖的核心项，删掉等于弃权；而且真机本身是通的
——同一天从网页入口连跑三次全部成功。要修的是等待体验，不是砍掉功能。

回归情况：八套自测（含新增的垫场结果 9 项）、六电路保真度回归、L1 三后端
全部通过。
改动后的界面见 `files/webui/`，其中 `09-fallback.png` 是真机整片离线时的
新版提示。
