# 五分钟引导实测记录

这是作者本人做的两轮测试记录。作者不是物理或量子专业，但因为熟悉页面，所以不能把这份记录当成陌生用户测试。

## 第一轮

| 项目 | 记录 |
|---|---|
| 时间 | 2026-08-12，约 20:20（UTC+8） |
| 被试 | A，项目作者本人；学生，非物理专业，没学过量子力学 |
| 入口 | 网页，Windows 11 + Edge |
| 模型/真机 | 都已配置；当天五个平台全部离线 |
| 首个结果 | 1 分 10 秒前已经出现在结果页，但走的是本地回退模拟器 |

实际反应：

```text
1.我没懂这个页面的名词和概念
基本都没看懂，不用挑了
黑话旁边直接跟一句人话，不用我去点
```

主要卡在“贝尔态”“受控非门”“纠缠”“线路深度”和 `gemini_vp` 这些词。真机离线时页面还把原因说成“电路太大”，这也是错的，实际原因是没有在线机器。

这一轮说明：流程能跑，但零基础用户看不懂，不能算专项奖通过。

## 第二轮

| 项目 | 记录 |
|---|---|
| 时间 | 2026-08-13 上午 |
| 使用版本 | `ec1644f` |
| 首个结果 | 约 1 分钟 |
| 自然语言输入 | `让三个比特全都纠缠起来` |
| 结果 | Agent 生成三比特 GHZ 电路并跑出结果 |
| 原理题 | 三题全对（当时没有逐题记下选项） |

第二轮没有再报告第一轮那些术语看不懂的问题。真机不是在主流程里点的，下午用同一个网页入口补跑了三比特 GHZ：

```text
平台：triangulum_vp
任务编号：S-260813-0002
结果：on_hardware=true
真机返回：约 123 秒
```

最后让被试回答“你刚才让那台机器做了什么？为什么会得到这些结果？”，回答基本复述了页面上的收尾文案，没有真正解释为什么只出现那些结果。因此“理解科学原理”这项仍只算部分完成。
